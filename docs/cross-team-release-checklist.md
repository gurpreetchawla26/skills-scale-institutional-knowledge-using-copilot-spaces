# Cross-team release readiness checklist

Use this checklist for multi-team or multi-service releases.

- [ ] Release owner identified (name, contact)
- [ ] Technical Program Manager / TPM has confirmed cross-team dependencies and timelines
- [ ] Feature acceptance criteria validated and covered by tests
- [ ] Security & Compliance checks completed or scheduled
- [ ] Support/Customer Success briefed on expected impact and communications
- [ ] Telemetry and dashboards instrumented and validated by Data Analyst
- [ ] Rollback and mitigation plan documented
- [ ] Post-deploy verification and smoke tests defined
- [ ] Communication plan (stakeholders + customers) prepared
